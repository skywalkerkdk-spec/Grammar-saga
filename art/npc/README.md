# NPC 그래픽 제작 파이프라인 (Chapter II)

주민 252명(기존 72 + 추가 180)에게 서로 다른 그림을 입히는 작업 안내입니다. **그림 생성은 GPT가, 검사·분할·게임 등록은 이 저장소의 도구가** 맡습니다.

## 현재 상태
- 제작 목록: `NPC_MANIFEST.json` / `.csv` (자동 산출, 252명 → 고정형 123 · 이동형 129, 직업 99종, 중복 ID·미배정 0)
- 이미지 요청서: `prompts/` (배치 71개: 이동형 M001~M065, 고정형 F001~F006). **원본 주민이 먼저 오도록 정렬**했습니다.
- 검사·분할 도구: `tools/npc_sheet_check.py`, `tools/npc_slice_batch.py` (합성 이미지로 테스트 통과)
- 게임 연결: `story/maps/npc-atlas.js`(등록부), `story/maps/npc-walk.js`(걷기). **등록된 그림이 0장이라 지금은 기존 그림 그대로**이며, 합격한 그림을 넣는 순간 자동으로 바뀝니다.
- **실제 NPC 그림은 아직 한 장도 만들지 못했습니다.** 저는 이미지를 생성할 수 없어 GPT에게 맡기는 구조입니다. 업로드된 시안(art_drafts)은 48명을 한 장에 넣어 칸이 너무 작고 흐려 규격 미달이라 사용하지 않았습니다.

## 규격 (게임 엔진 기준)
| 종류 | 대상 | 규격 |
|---|---|---|
| 이동형 | 걷는 주민(129명) | 개별 시트 **1024×512 RGBA**, 8열×4행, 칸 128×128. 행: 아래·왼쪽·오른쪽·위(뒷모습). 3번째 칸이 가만히 서 있는 기본 프레임. 발 기준선 y=116 고정 |
| 고정형 | 가게·건물에 서 있는 주민(123명) | **128×128 RGBA** 정면 전신 1컷, 발 중심 약 (64,118) |
성인 높이 약 100px, 어린이 약 80px. 배경·글자·번호·구분선 없음, 실제 알파 투명.
(이동형 규격은 GPT가 만든 주인공 걷기 시트 `story/maps/wk_*_walk8.webp`와 같습니다. 인수인계서의 4×4 제안은 엔진에 쓰이지 않아 이 규격을 따랐습니다.)

## 작업 순서
1. `prompts/M001.md`처럼 배치 파일을 GPT에 붙여 넣고, 화풍 기준으로 `story/maps/wk_tank_walk8.webp`와 `story/maps/villages/*.webp` 몇 장을 첨부합니다.
2. GPT가 만든 이미지(이동형 1024×1024, 고정형 1536×1024)를 저장소 밖 임시 폴더에 저장합니다.
3. `python3 tools/npc_slice_batch.py M001 batch_M001.png` → NPC별로 잘라 `art/npc/sprites/npc_<ID>.webp`로 저장하고 즉시 검사합니다. 불합격 NPC 목록이 나오면 그 인물만 다시 요청합니다.
4. `python3 tools/npc_build_atlas.py` → 합격한 것만 `story/maps/npc-atlas.js`에 등록합니다.
5. `GRAMMAR_CHROMIUM=<크롬경로> python3 tests/check_npc_walk.py` 와 기존 Chapter II 테스트로 확인합니다.
6. 별도 승인 후 배포합니다(메인 병합은 하지 않았습니다).

## 검사기가 잡는 것
크기·알파·체커보드 배경·빈 칸·칸 경계 잘림·발 기준선 흔들림·프레임별 키 차이·걷는 동작 없음·방향별 옷 색 불일치(경고). 눈으로 보는 **화풍·인물 일관성 최종 확인은 사람이 해야 합니다**.

## 걷기 동작 (구현됨)
- 시트가 등록된 이동형 주민만 반경 3칸 안에서 천천히 돌아다닙니다. 길이 아닌 곳·주인공·다른 주민 자리는 피합니다.
- 대화 상자가 열리면 멈추고, 주인공이 바로 옆이면 그쪽을 봅니다. 장면이 닫히면 타이머도 끝납니다.
- 누르면 주민의 **현재 위치** 옆으로 주인공이 걸어갑니다. 위치는 저장하지 않으므로 저장 데이터에 영향이 없습니다.
- 시트가 없거나 불러오기에 실패하면 기존 정지 그림을 씁니다.

## 우선순위 제안
이동형 배치 중 M001~M026이 **기존 원본 주민**(현재 화면에 보이는 사람들)이므로 먼저 만들고, 이어서 고정형 F001(원본 고정형 포함), 나머지 추가 주민 순으로 진행하세요.
